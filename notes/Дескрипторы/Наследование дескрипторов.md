Если объект некоторого процесса *наследуемый*,  то к нему будут также иметь доступ все процессы, которые создаются этим процессом, т.е. его потомки. 

Не наследуются из-за нарушения изоляции памяти: LocalAlloc, GlobalAlloc, HeapCreate, HeapAlloc, HANDLE LoadLibrary().

Передавать дескрипторы от родительского потока дочернему можно через аргументы командной строки.
```C++
int main(int argc, char *argv[])
{
	HANDLE hThread;
	hThread = (HANDLE)atoi(argv[1]);
	...
	TerminateThread(hThread, 0);
	CloseHandle(hThread);
	
	return 0;
}
```

```C++
	DWORD  dwFlags   // новые значения флагов

```

```C++
BOOL GetHandleInformation(
```
