*Псевдодескриптор* отличается от обычного дескриптора тем, что он может использоваться только самим текущим потоком.

Из псевдодескриптора можно получить настоящий дескриптор, для этого надо продублировать псевдодескриптор, вызвав `DublicateHandle`.

Получить псевдодескриптор потока:
```C++
HANDLE GetCurrentThread(VOID);
```

Получить псевдодескриптор процесса:
```C++
HANDLE GetCurrentProcess(VOID);
```

Чтобы получить наследуемый дескриптор потока необходимо дублировать его псевдодескриптор:
```C++
HANDLE hInheritThread;
HANDLE hThread;

hThread = CreateThread(...);
if (hThread == NULL){
	return GetLAstError();
}

DublicateHandle(
	GetCurrentProcess(),
	hThread,
	GetCurrentProcess(),
	&hInheritThread,
	0,
	TRUE,
	DUBLICATE_SAME_ACCESS
);
```
Затем передать дескриптор дочернему процессу можно через аргументы командной строки
