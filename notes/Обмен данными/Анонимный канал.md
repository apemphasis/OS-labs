— объект ядра ОС, который обеспечивает передачу данных между процессами.

**Сервер АК** — процесс, который создает АК
**Клиент АК** — процесс, который связывается с АК

Характеристики: 
- не имеют имени
- полудуплексные
- передача данных потоком
- синхронный обмен данными
- возможность моделирования любой топологии связей

Порядок работы:
- создание анонимного канала сервером
- соединение клиентов с каналом
- обмен данными по каналу
- закрытие канала

# Интерфейс
## Создание
```cpp
BOOL CreatePipe(
	PHANDLE hReadHandle,
	PHANDLE hWriteHandle,
	LPSECURITY_ATTRIBUTES lpPipeAttributes,
	DWORD dwSize    // Размер буфера в байтах 
)
```
## Запись
```cpp
BOOL WriteFile(
	HANDLE hAnonymousPipe,
	LPCVOID lpBuffer,
	DWORD dwNumberOfBytesToWrite,
	LPDWORD lpNumberOfBytesWritten,
	LPOVERLAPPED lpOverLapped // NULL
)
```
## Чтение
```cpp
BOOL ReadFile(
	HANDLE hAnonymousPipe,
	LPCVOID lpBuffer,
	DWORD dwNumberOfBytesToRead,
	LPDWORD lpNumberOfBytesRead,
	LPOVERLAPPED lpOverlapped // NULL
)
```
