— пересылка данных между потоками, которые выполняются в контексте разных процессов.

Отправитель —> Адресат (Получатель)

Способы передачи данных:
- потоком
- сообщениями

##### Классификация связей
###### По направлению
- полудуплексная
- дуплексная
###### По топологии
- 1 -> 1
- 1 -> N
- N -> 1
- N -> M

##### Протокол
— набор правил, по которым устанавливаются связи и передаются данные между процессами
