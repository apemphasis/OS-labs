Функции, параметрами которых являются объектами синхронизации.

Мы работаем с 
``` c++
DWORD WaitForSingleObject(
	HANNDLE hHandle,
	DWORD   dwMilliseconds
)

// Return values

WAIT_OBJECT_0 //объект синхронизации находился или перешел в сигнальное состояние
WAIT_ABANDONED // объектом синхронизации был мьютекс, который не был освобожден потоком, завершившим свое выполнение 
WAIT_TIMEOUT // время ожидания истекло, а объект синхронизации не перешел в сигнальное состояние
WAIT_FAILED // в случае неудачи
```

```c++
DWORD WaitForMultipleObjects(
	DWORD nCount,
	CONST HANDLE *lpHandles,
	BOOL  bWaitAll,
	DWORD dwMilliseconds
)
```
Количество ожидаемых объектов синхронизации не должно превышать MAXIMUM_WAIT_OBJECTS

Return values

1. от WAIT_OBJECT_0 до (WAIT_OBJECT_0+nCount-1)
2. от WAIT_ABANDONED_0 до (WAIT_ABANDONED_0+nCount-1)
3. WAIT_TIMEOUT

Интерпретация значений зависит от значения bWaitAll

TRUE: 
1. любое значение от `WAIT_OBJECT_0` до `(WAIT_OBJECT_0+nCount-1)` означает, что все объекты синхронизации находились или перешли в сигнальное положение
2. любое значение от `WAIT_ABANDONED_0` до `(WAIT_ABANDONED_0+nCount-1)` означает, что все объекты находились или перешли в сигнальное и как минимум один из них был забытым мьютексом 
3. WAIT_TIMEOUT означает, что время ожидания истекло и не все объекты синхронизации перешли в сигнальное состояние

FALSE:
1. любое значение от `WAIT_OBJECT_0` до `(WAIT_OBJECT_0+nCount-1)` означает, что по крайней мере один из объектов находился или перешел в сигнальное состояние. Индекс его дескриптора в массиве есть разница возвращаемого значения и `WAIT_OBJECT_0`
2. любое значение от `WAIT_ABANDONED_0` до `(WAIT_ABANDONED_0+nCount-1)` означает, что одним из объектов синхронизации, перешедших в сигнальное состояние, является забытый мьютекс. Индекс дескриптора этого мьютекса в массиве есть разница возвращаемого значения и `WAIT_ABANDONED_0`
3. WAIT_TIMEOUT означает, что время ожидания истекло и ни один объект синхронизации не перешел в сигнальное состояние
