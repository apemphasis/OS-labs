# Интерфейс
## Захват ф-й ожидания
**`-1`**
Значение семафора уменьшается на 1 при его использовании в функции ожидания.
## Освобождение
**`+1`**
Увеличивает значение семафора ф-я:
```cpp
BOOL RealeaseSemaphore(
	HANDLE hSemaphore,
	LONG   lReleaseCount,  // +число, насколько увеличить
	LPLONG lpPreviousCount // предыдущее значение
)
```
