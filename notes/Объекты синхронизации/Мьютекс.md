Объект ядра, который служит для решения проблемы взаимного исключения между параллельными потоками в контексте разным процессов.

Мьютекс имеет два состояния:
- сигнальное - не принадлежит ни одному потоку
- несигнальное - иначе (может принадлежать одновременно только одному потоку)

##### Интерфейс:

###### CreateMutex

```c++
HANDLE CreateMutex(
	LPSECURITY_ATTRIBUTES lpMutexAttributes,
	BOOL                  bInitialOwner,
	LPCTSTR               lpName
)
```

Если значение параметра bInitialOwner равно TRUE, то мьютекс сразу переходит во владение потоку, который его создал.
Имя мьютекса должно быть уникальным.

###### CaptureMutex
Мьютекс захватывается потоком посредством любой [[Функции ожидания|функции ожидания]]. 

###### ReleaseMutex

```c++
BOOL ReleaseMutex(
	HANDLE hMutex
)
```

Освобождает мьютекс которым владеет этот поток. Если поток мьютексом не владеет вернет FALSE

###### OpenMutex

```c++
HANDLE OpenMutex(
	DWORD   dwDesiredAccess,
	BOOL    bInheritHandle,
	LPCTSTR lpName
)
```
Получает доступ к уже существующему мьютексу с определением параметров доступа.

Допустимые значения для dwDesiredAccess:
- MUTEX_ALL_ACCESS - полный доступ к мьютексу
- SYNCRONIZE - поток может использовать мьютекс только в [[Функции ожидания|функциях ожидания]], чтобы захватить мьютекс, или в ReleaseMutex, для его освобождения
