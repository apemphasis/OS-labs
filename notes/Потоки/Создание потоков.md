```C++
HANDLE CreateThread(
	LPSECURITY_ATTRIBUTES lpThreadAttributes,
	DWORD    dwStackSize // default 1Mb
	LPTHREAD_START_ROUTINE lpStartAddress, // func addr
	LPVOID   lpParameter,                  // the only param
	DWORD    dwCreationFlags,
	LPDWORD  lpThreadId
)
```
Сигнатура исполняемой потоком функции (*функция обратного вызова*):
`DWORD WINAPI func_name(LPVOID lpParameters);`

| dwCreationFlags value | Description                                                     |
| --------------------- | --------------------------------------------------------------- |
| 0                     | функция потока начинает выполняться сразу после создания потока |
| CREATE_SUSPEND        | поток создается в подвешенном состоянии                         |
Пример 1:
```C++
volatile int N;

DWORD WINAPI thread(LPVOID inc) {
	N += (int)inc;
	cout << N << endl;
```
