Поток  -  объект ядра, которому ОС выделяет процессорное время для выполнения.

Ресурсы(контекст) потока:
- код исполняемой функции
- набор регистров процессора
- стек для работы приложения
- стек для работы операционной системы
- маркер доступа, который содержит информацию для системы безопасности

Параллельные потоки - потоки, выполнение которых перекрывается во времени.

Взаимодействующие потоки - параллельные потоки, которые обмениваются некоторыми сигналами.

Асинхронные потоки - потоки, которые работают независимо друг от друга. 

Сигналы, которые обмениваются взаимодействующие потоки, могут быть двух типов:
###### Управляющие сигналы
Предназначены для координации работы взаимодействующих потоков.
###### Сигналы данных
Предназначены для обмена данными между параллельными потоками.

Синхронизация потоков - обмен управляющими сигналами между параллельными потоками по установленному протоколу для обеспечения координации их действий. 

Протокол - набор правил, по которым выполняется обмен этими сигналами.
