Каждый поток имеет счетчик приостановок, максимальное значение которого равно MAXIMUM_SUSPEND_COUNT. Поток может исполняться только если счетчик равен нулю. В противном случае поток находится в подвешенном состоянии.

Приостановка потока (счетчик++) :
```C++
DWORD SuspendThread(
	HANDLE hThread
)
```

Возобновление потока (счетчик--) :
```C++
DWORD ResumeThread(
	HANDLE hThread
)
```

Перевод в спящий режим:
```
VOID Sleep(
	DWORD dwMilliseconds
)
```
