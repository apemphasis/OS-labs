# Создание или открытие файла:
```c++
HANDLE CreateFile(
	LPCTSTR lpFileName,                         // имя файла
	DWORD   dwDesiredAccess,                    // способ доступа
	DWORD   dwShareMode,                        // режимы совместного доступа
	LPSECURITY_ATTRIBUTES lpSecurityAttributes, // NULL - атрибуты защиты
	DWORD   dwCreationDisposition,              // создание или открытие файла
	DWORD   dwFlagsAndAttributes,               // флаги и атрибуты
	HANDLE  hTemplateFile	                    // файл атрибутов
);
```


| **Аргумент**           | Возможные значения                                                                                                                                                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| dwDesiredAccess        | 0 \| GENERIC_READ \| GENERIC_WRITE                                                                                                                                                                                                                                                                                                                      |
| dwShareMode            | FILE_SHARE_READ \| FILE_SHARE_WRITE \| FILE_SHARE_DELETE                                                                                                                                                                                                                                                                                                |
| dwCreateionDisposition | CREATE_NEW<br>CREATE_ALWAYS - если уже сущ => удаляется и создается новый<br>OPEN_EXISTING<br>OPEN_ALWAYS - если не сущ => создает новый<br>TRUNCATE_EXISTING - открыть файл и уничтожить его содержимое                                                                                                                                                |
| dwFlagsAndAttributes   | FILE_ATTRIBUTE_ENCRYPTED<br>FILE_ATTRIBUTE_ARCHIVE<br>FILE_ATTRIBUTE_HIDDEN<br>FILE_ATTRIBUTE_NORMAL - не имеет других атрибутов<br>FILE_ATTRIBUTE_NOT_CONTENT_INDEXED<br>FILE_ATTRIBUTE_OFFLINE - находится во вспомогательной памяти<br>FILE_ATTRIBUTE_READONLY<br>FILE_ATTRIBUTE_SYSTEM - используется ОС<br>FILE_ATTRIBUTE_TEMPORARY<br>... стр 426 |
Пример:
```C++
HANDLE hFile;

hFile = CreateFile(
	"demo-file.dat", 
	GENERIC_WRITE, 
	0, 
	NULL, 
	CREATE_NEW, 
	FILE_ATTRIBUTE_NORMAL, 
	NULL
);

if (hFile == INVALID_HANDLE_VALUE){
	return GetLastError();
}
```

# Запись в файл
```C++
BOOL WriteFile(
	HANDLE  hFile,                  
	LPCVOID lpBuffer,               // указатель откуда писать
	DWORD   nNumberOfBytesToWrite,  // кол-во записываемых байт
	DWORD   lNumberOfBytesWrittem,  // кол-во записанных (не NULL)
	LPOVERLAPPED lpOverlapped       // NULL
);
```
Пример:
```C++
int i = 10;
DWORD dwBytesWritten;

if (!WriteFile(
		hFile,
		&i, 
		sizeof(i), 
		&dwBytesWritten, 
		(LPOVERLAPPED)NULL
	))
{
	return GetLastError();
} 
```

# Чтение из файла
```C++
BOOL ReadFile(
	HANDLE hFile,
	LPVOID lpBuffer, 
	DWORD  nNumberOfBytesToRead, 
	DWORD  lpNumberOfWordsRead, 
	LPOVERLAPPED lpOverlapped

```
Пример:
```C++
int n;
DWORD dwBytesRead

if (!ReadFile(
		hFile, 
		&n, 
		sizeof(n),

	return GetLastError();
}
```
